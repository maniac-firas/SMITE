# SMITE
SMITE stands for Software Management Inventory Technological Environment. (Purposefully made it this way).

This is a school project. Using tkinter and other modules, written entirely in python language, it is a fully-functional Storage Inventory Management System.

To run the program, run the program called Store Inventory Management System.py in tkinter directory. The program asks for your mysql local root password which ensures that the database runs in any system. Any and all changes to the database are made permanently and tracked in the .csv files available everywhere. 

The Store Inventory Management System.py file contains the main code and all other code for each window such as display, enter, pick or refill are stored in their respective files. The Project Code.py file contains all the aforementioned files together and in one single file. Both program will work flawlessly and to no issues. 

All operations work well and are stored in the Functions directory. It is being used as a module for the main code in order to avoid redundancy. Database Creators directory has files which were used to automate the database and the data for it at the beginning stage of this project. 

There might be a few files that render useless to the main program which were used for debugging and references.
